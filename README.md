# 💈 Projeto Barbeweb
Repositório destinado ao projeto do sistema **Barbeweb** da disciplina de **Desenvolvimento Web I** do curso de **ADS**.

🌐 **Link do site:** [barbeweb-app.vercel.app](https://barbeweb-app.vercel.app/)

## 📝 Resumo do Projeto
O projeto consiste no desenvolvimento de um protótipo de aplicativo para uma barbearia local, voltado tanto para os clientes quanto para a administração do estabelecimento. O aplicativo tem como objetivo facilitar o processo de agendamento de serviços, permitindo que os clientes consultem os serviços disponíveis, os preços e os horários disponíveis. Além disso, o sistema busca melhorar a organização da agenda da barbearia e proporcionar maior praticidade no atendimento. A proposta foi desenvolvida pensando na modernização de pequenos negócios locais, utilizando a tecnologia como ferramenta para melhorar a experiência dos clientes e otimizar a gestão dos agendamentos.

## ▶️ Como executar o projeto

### Requisitos

Tenha o [Node.js](https://nodejs.org/) e o npm instalados.

### Passos

1. Clone o repositório e entre na pasta do projeto:

   ```bash
   git clone https://github.com/Thalessantos7/projeto-desenvolvimento-web.git
   cd projeto-desenvolvimento-web
   ```

2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

4. Abra [http://localhost:3000](http://localhost:3000) no navegador.

## 💻 Tecnologias Utilizadas

O frontend do Barbeweb está sendo desenvolvido com foco em um ecossistema moderno e componentizado, garantindo uma interface responsiva e fiel ao protótipo. As principais tecnologias incluem:

* 🚀 **Next.js**: Framework React responsável pela estruturação do projeto e sistema de rotas.
* 📘 **TypeScript**: Superset de JavaScript que adiciona tipagem estática, garantindo maior segurança e previsibilidade no código.
* 💨 **Tailwind CSS**: Framework CSS utilitário utilizado para a estilização rápida e construção do layout visual de forma responsiva.
* ✨ **Lucide React**: Biblioteca de ícones limpos e consistentes, aplicados nos inputs e elementos interativos dos formulários.
* 🎨 **Figma**: Ferramenta de design utilizada pela equipe para a criação do protótipo de alta fidelidade e planejamento da UI/UX.

## ✂️ Funcionalidades do Projeto

* Tela de login e seleção de perfil para clientes e profissionais.
* Formulários de cadastro para clientes e profissionais.
* Consulta dos horários disponíveis da barbearia.
* Tela de agendamento com escolha de serviço, exibição do preço e confirmação visual.
